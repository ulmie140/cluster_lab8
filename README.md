# Экспертная система: Кластерный анализ

> Интеллектуальное веб-приложение для автоматической группировки (кластеризации) вычислительной техники (ноутбуков) по степени их технического сходства. Проект разработан в рамках лабораторной работы №8 по дисциплине "Базы знаний и поддержка принятия решений".

## Описание задачи
Система выполняет машинное обучение без учителя, самостоятельно разбивая множество из 12 объектов (ноутбуков) на кластеры на основе 3 ключевых признаков:
1. Частота процессора (ГГц)
2. Объем оперативной памяти (ГБ)
3. Масса (кг)

## Реализованные алгоритмы
- **Метод К-средних:** Разделение множества на заданное пользователем число кластеров (K) с итеративным пересчетом координат геометрических центров (прототипов) до полной стабилизации групп.
- **Метод Максимина:** Алгоритм с автоматическим определением оптимального количества кластеров. Выполняет поиск наиболее удаленных объектов и формирует новые группы на основе вычисляемых пороговых расстояний.

## Технический стек и Архитектура
Проект построен по принципам чистой архитектуры (Clean Architecture), изолирующей математическое ядро от веб-фреймворка:
- **Domain** (`src/domain/models.py`): Структуры данных и модели объектов кластеризации.
- **Service** (`src/services/clustering.py`): Бизнес-логика, вычисление евклидовых расстояний и алгоритмы группировки данных.
- **Web** (`src/web/`): REST API на **Flask**, адаптивный интерфейс на **Tailwind CSS** и интерактивная визуализация данных (Bubble Chart) с помощью **Plotly.js**.

## Запуск проекта

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Запустите сервер: `python main.py`
3. Откройте в браузере: `http://127.0.0.1:5000`
